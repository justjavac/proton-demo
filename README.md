# Proton Starter

An isomorphic MoonBit Todo app generated by `proton_cli new`.

- `shared/` defines the typed commands, events, and payloads used on both sides.
- `frontend/` is a Rabbita application built and served by Warren.
- `backend/` owns the in-memory Todo state and runs the Proton desktop runtime.

## Setup

```sh
moon update
moon install justjavac/proton_cli
moon install moonbit-community/warren
proton_cli cef setup
```

## Check

```sh
moon check --target js,native --diagnostic-limit 80
```

## Dev

```sh
proton_cli dev
```

`dev` starts Warren in `frontend/`, waits for the development URL, then runs
`backend/app`.

## Build

```sh
proton_cli build
```

`build` runs `warren build` in `frontend/`, validates `frontend/dist`, and
builds `backend/app` for the native target.

```sh
proton_cli build -- --release
```

## Bundle

The `bundle` block in `moon.proton` controls package creation:

```moonbit
bundle = {
  active: true,
  targets: ["app", "zip"],
  output: "target/proton-dist",
}
```

Inspect the resolved package plan, then create the application and zip archive:

```sh
proton_cli package --dry-run
proton_cli package
```

## Layout

- `shared/todo_contract.mbt` is the cross-target contract source of truth.
- `frontend/main/main.mbt` handles Rabbita state, commands, and live events.
- `backend/todo/` owns state and typed command handlers.
- `backend/todo/commands.g.mbt` is generated during check and build.
- `backend/app/main.mbt` assembles and runs the application.
- `target/proton-dist/` contains packaged application artifacts.

## Demos

The `demos/` module contains three standalone Proton windows with plain
HTML/CSS/JS frontends:

- `demos/todolist` — todo list with filters and localStorage persistence.
- `demos/calculator` — four-function calculator with keyboard support.
- `demos/spinning_cube` — CSS 3D cube with auto-rotation and drag control.

Run any of them from the repository root after `proton_cli cef setup`:

```sh
moon run demos/todolist --target native
moon run demos/calculator --target native
moon run demos/spinning_cube --target native
```
